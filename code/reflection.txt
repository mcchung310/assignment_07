What I learned from this assignment were skills that I will definitely being using
going forwards for my end of semester project. I learned is that scraping starts 
with figuring out where the data actually lives. Lakeshore had it in the HTML, 
so a class selector on each h2 plus the sibling selector ~ div.menu-grid connected 
every category to its cards, and inner_text gave me the raw card text to clean. 
Hilltop had real tables, so read_html and melt turned the S/M/L columns into one 
row per size. Canal was the hardest because the menu isn't in the HTML at all. 
I needed a headless browser to click through it, handle pagination with 
"Show more," keep waiting for JavaScript after every click, and crawl each item 
page using its href attribute. Skipping a wait doesn't throw an error, it just 
quietly gives you fewer rows. Matching taught me that fuzzy matching compares 
spelling, not meaning. Normalization helps, but "Matcha Latte" still scores 
87 against "Mocha Latte" and is a different drink, while "PSL" scores near 
0 and is the same as our Pumpkin Spice Latte. That's why the threshold sends 
anything under 90 to a human in the loop. Then an outer merge with the merge 
indicator did most of the gap analysis, showing 25 prices below the market, 
10 above, and 8 items only the rivals sell.

I also got some matches wrong the first time so I had to redo it. Next time
